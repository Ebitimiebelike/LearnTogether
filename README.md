# LearnTogether

An offline-first learning app for letters, numbers, tracing and early literacy —
built for learners who need large touch targets, audio support, repetition and
encouragement, including learners with motor and speech differences.

No ads. No account. No timers. Nothing that punishes a wrong answer.

**[Open the app →](https://learn-together-umber.vercel.app)**

---

## Install it

Open the link above on a phone or tablet and tap **Install app**.

| Platform | What happens |
| --- | --- |
| Android / Chrome | The native install dialog opens. One tap. |
| iPhone / iPad | Safari has no install API, so the button shows the Share → *Add to Home Screen* steps. |
| Desktop | It runs in the browser; the page explains where installing is possible. |

Once installed it launches from the home screen like any other app — full
screen, no browser bars — and **works with no internet at all**. Every screen is
cached during install, including letters and numbers the learner has never
opened.

## What it does

**Learn**
- Alphabet A–Z, each letter with its lowercase form, an example word, a picture,
  and a separate button for the sound the letter makes
- Numbers 0–20, each with its written word and that many objects to count
- Tapping any letter or number reads it aloud

**Trace**
- Finger-tracing for uppercase letters, lowercase letters, and numbers 0–20
- Numbered start points and direction arrows on every stroke
- Gentle, encouraging feedback — the score only picks the message, never blocks
  progress

**Practice and play**
- Find the letter / find the number, from a spoken prompt
- Listen and choose, with no written clue
- Tap-to-select matching (A → Apple, 3 → three objects)

**Progress and rewards**
- Stars, badges and a day streak — no leaderboards, no comparison to anyone else
- A visual progress screen: introduced, practising, mastered
- A PIN-protected caregiver dashboard showing what was practised, what needs
  more work, recent sessions and total learning time

## Built for accessibility

These are enforced in the design system and shared components, not left to
individual screens:

- **56 px minimum touch target.** Answer tiles are far larger again.
- **No timers anywhere.** Nothing is on a clock.
- **No flashing.** Animations are short, single-shot, and respect
  `prefers-reduced-motion`.
- **Wrong answers are never punished.** A wrong tap plays a soft tone, says
  "Good try", repeats the instruction, and leaves every option enabled. Retries
  are unlimited, and only the first attempt is scored.
- **Colour is never the only cue.** Correct answers show a check mark as well as
  turning green.
- **The learner never has to speak, read much, or write accurately.**
- **Three taps or fewer** from Home to any activity.
- 18 px base text, high contrast in both light and dark themes.

## Tech

Next.js 16 · TypeScript · Tailwind CSS v4 · PWA (Serwist) · IndexedDB · Vitest

Some deliberate choices:

- **Lessons are data, not markup.** Every screen renders from
  `src/data/`, so content can be extended or translated without touching
  components.
- **Domain logic is pure and lives outside React** — mastery, rewards, question
  generation and trace scoring are plain functions, which is why they are
  directly testable.
- **Storage sits behind repository interfaces**, so cloud sync can be added
  later without changing any UI.
- **Zero runtime CDN dependencies.** Illustrations are emoji, sound effects are
  synthesised with the Web Audio API, and the theme music and icons are
  generated by scripts in the repo — no third-party assets, no licensing
  questions.

**337 tests** cover progress, rewards, storage, question generation, trace
scoring, pointer events and end-to-end flows. Several assert the app's promises
directly: that a wrong answer leaves the correct option enabled, that feedback
never contains discouraging wording, and that no screen shows a countdown.

## Running it locally

```bash
cd learntogether
npm install
npm run dev          # http://localhost:3000
```

Offline support needs a production build — the service worker is not generated
in development:

```bash
npm run build && npm start
```

Full commands, architecture notes, deployment settings and known limitations are
in **[`learntogether/README.md`](learntogether/README.md)**.

## Status

The MVP is complete and deployed. Alphabet, numbers, tracing, identification,
listening, matching, rewards, progress and the caregiver dashboard all work, and
the whole app runs offline once installed.

Known limitations are documented honestly in the
[app README](learntogether/README.md#known-limitations). In short: illustrations
are emoji rather than commissioned artwork, speech uses the device voice rather
than recordings (both have the swap-in path already built), trace scoring is
coverage rather than handwriting recognition, and the caregiver PIN is a lock
rather than a security boundary.
