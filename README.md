# LearnTogether

LearnTogether is an offline-first educational platform designed to help children develop literacy, numeracy, and communication skills through interactive, accessible learning experiences.

## Vision

Every child deserves the opportunity to learn at their own pace.

LearnTogether focuses on simple, distraction-free learning using visual aids, audio guidance, repetition, and positive reinforcement.

## Features (Planned)

- Offline-first experience
- Alphabet learning
- Number recognition
- Everyday words
- Interactive learning games
- Progress tracking
- Parent dashboard
- Accessibility-first design
- Progressive Web App (PWA)

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- PWA
- IndexedDB
