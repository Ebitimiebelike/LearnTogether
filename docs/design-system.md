# Design System

## Design Principles

- Accessibility First
- Simple over Complex
- One Task Per Screen
- Large Touch Targets
- Consistency
- Positive Reinforcement

---

# Colors

## Primary

Blue

Purpose:
Primary buttons, active states, navigation

---

## Success

Green

Purpose:
Correct answers
Rewards
Progress

---

## Warning

Yellow

Purpose:
Hints
Achievements

---

## Error

Soft Red

Purpose:
Friendly error messages

---

## Neutral

White
Light Gray
Dark Gray

Purpose:
Backgrounds
Text
Cards

---

# Typography

Headings

- Bold
- Large
- Easy to read

Body Text

- Medium size
- High contrast

Buttons

- Bold

Never use decorative fonts.

---

# Spacing

Small

8px

Medium

16px

Large

24px

Extra Large

32px

Use consistent spacing throughout the application.

---

# Border Radius

Cards

16px

Buttons

16px

Images

12px

The interface should feel soft and friendly.

---

# Buttons

Primary Button

- Filled
- Rounded
- Large

Secondary Button

- Outline

Icon Button

- Circular

Buttons should always be easy to tap.

Minimum height:

56px

---

# Icons

Use simple filled icons.

Avoid detailed illustrations inside icons.

---

# Cards

Cards contain:

- Lesson
- Progress
- Games
- Rewards

Every card should have:

- Rounded corners
- Soft shadow
- Comfortable padding

---

# Images

Images should:

- Be colorful
- Be recognizable
- Match real-world objects

Avoid overly detailed artwork.

---

# Audio

Every lesson should have a speaker button.

Audio should:

- Be clear
- Be slow
- Be encouraging

---

# Animations

Animations should be:

- Short
- Smooth
- Rewarding

Never distracting.

Examples:

⭐ Stars

🎈 Balloons

🎉 Confetti

---

# Accessibility

Minimum touch target:

56 x 56 px

Minimum font size:

16 px

High contrast

Readable typography

Simple navigation

No flashing animations

No time-limited interactions

---

# Component Library

Components used throughout the app:

- Button
- Card
- Lesson Card
- Progress Card
- Avatar Card
- Audio Button
- Navigation Bar
- Progress Bar
- Badge
- Modal
- Dialog

Every component should be reusable.
