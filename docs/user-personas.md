# User Personas

LearnTogether is designed around real people, not abstract "users."

Every feature should solve a real problem experienced by one or more of the personas below.

---

# Persona 1 — The Learner

## Profile

Name: Daniel (Example)

Age: 8–18 years

Description:

Daniel is a child who learns differently.

He may have cerebral palsy, a speech impairment, developmental delay, autism, Down syndrome, ADHD, dyslexia, or simply need additional time and repetition.

He enjoys learning through:

- Pictures
- Music
- Repetition
- Positive encouragement
- Touch interaction

He may struggle with:

- Reading
- Writing
- Fine motor control
- Speaking clearly
- Maintaining attention

## Goals

- Learn letters
- Learn numbers
- Read simple words
- Communicate more confidently
- Learn independently

## Frustrations

- Tiny buttons
- Complex interfaces
- Advertisements
- Timed quizzes
- Negative feedback
- Too much information on one screen

## Product Decisions

Because of this learner:

✓ Use large buttons

✓ Keep one task per screen

✓ Include audio instructions

✓ Celebrate every success

✓ Never punish mistakes

# Persona 2 — Parent / Caregiver

## Profile

Parents want to help but often have:

- Limited time
- Limited money
- Limited access to therapists
- Limited internet connectivity

Many practice with their child every evening after school.

## Goals

- Track progress
- Continue learning at home
- Encourage consistency
- Celebrate improvements

## Frustrations

- Expensive subscriptions

- Internet requirements

- Advertisements

- No way to measure progress

## Product Decisions

✓ Offline support

✓ Parent Dashboard

✓ Daily progress

✓ Learning streaks

✓ Easy lesson selection

---

# Persona 3 — Teacher

## Profile

Teachers often work with multiple learners at once.

They need lessons that are:

- Easy to understand
- Repeatable
- Visual
- Quick to launch

## Goals

- Reinforce classroom learning
- Keep students engaged
- Reduce lesson preparation time

## Product Decisions

✓ Organized lesson categories

✓ Repeat lesson option

✓ Simple navigation

---

# Persona 4 — Speech Therapist

## Profile

Speech therapists help children improve communication.

They may recommend activities between therapy sessions.

## Goals

- Reinforce vocabulary
- Encourage repetition
- Improve communication confidence

## Product Decisions

✓ Audio playback

✓ Vocabulary lessons

✓ Simple communication exercises

---

# Persona 5 — Future Learners

LearnTogether should never assume one learning style.

Future learners may include:

- Neurotypical children

- Children learning English

- Adults learning basic literacy

- Children recovering from illness

- Refugee learners

- Elderly adults relearning cognitive skills

The platform should remain flexible enough to support them.

# Accessibility Requirements

Every feature should satisfy these principles.

## Visual

- Large text

- High contrast

- Friendly illustrations

## Motor

- Large touch targets

- Minimal dragging

- No complex gestures

## Cognitive

- One concept per lesson

- One task per screen

- Consistent layouts

- Repetition

## Hearing

- Visual alternatives for sounds

## Speech

- No requirement to speak correctly to continue learning

---

# Design Rule

Whenever a new feature is proposed, ask:

"Would this make learning easier for Daniel?"

If the answer is no,

the feature should be reconsidered.
