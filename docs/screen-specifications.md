# Screen Specifications

---

# 1. Splash Screen

Purpose:
Display branding while the app loads.

Components:
- Logo
- App Name

Actions:
- Automatically navigate to Onboarding or Home

---

# 2. Onboarding

Purpose:
Explain LearnTogether.

Components:
- 3 onboarding slides
- Next button
- Skip button
- Get Started button

Actions:
- Next
- Skip
- Start Setup

---

# 3. Create Learner

Purpose:
Create the learner profile.

Components:
- Name
- Age
- Continue button

Actions:
- Save profile
- Continue

---

# 4. Choose Avatar

Purpose:
Personalize the experience.

Components:
- Avatar grid
- Continue button

Actions:
- Select avatar
- Continue

---

# 5. Home

Purpose:
Main navigation.

Components:
- Greeting
- Continue Learning
- Learn
- Games
- Progress
- Parent Dashboard
- Settings

Actions:
- Open any module

---

# 6. Lesson

Purpose:
Teach one concept.

Components:
- Letter/Number/Image
- Audio button
- Next button

Actions:
- Listen
- Continue

---

# 7. Practice

Purpose:
Check understanding.

Components:
- Question
- Answer choices

Actions:
- Select answer
- Receive feedback

---

# 8. Reward

Purpose:
Celebrate progress.

Components:
- Stars
- Encouraging message
- Continue button

Actions:
- Continue learning

---

# 9. Games

Purpose:
Reinforce learning.

Components:
- Game list

Actions:
- Start game

---

# 10. Progress

Purpose:
Show learner growth.

Components:
- Letters learned
- Numbers learned
- Words learned
- Streak

Actions:
- View progress

---

# 11. Parent Dashboard

Purpose:
Help caregivers monitor learning.

Components:
- Practice history
- Recommendations
- Statistics

Actions:
- Review progress

---

# 12. Settings

Purpose:
Configure the app.

Components:
- Audio
- Language
- Theme
- Accessibility

Actions:
- Update settings
